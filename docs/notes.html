Residue numbering

cpptraj residue numbers in the stripped topology (*_nowater.prmtop, residues 1–16 kept by strip !:1-16):

cpptraj :12345678910111213141516
residueACELIVAGXNHEACELIVAGXNHE
positioncap123456capcap123456cap
peptidepeptide 1peptide 2

"Pair (i, j)" always means position i on peptide 1 (residue i+1) and position j on peptide 2 (residue j+9), so the 6×6 grids are not symmetric: (1, 2) and (2, 1) are different distances. In cross-system plots residue 6 is written X (e.g. L1–X6, window AGX).

Potentials of mean force

  • Distances: cpptraj distance between residue masks (centre of mass, minimum image) on com_frames_nowater.dcd (600,000 frames, peptides only), written to pmf_distances.dat in Å and converted to nm. 36 single-residue pairs, the LIVA fragment (:2-5 vs :10-13) and 16 three-residue window distances.
  • PMF(r) = −kBT ln P(r), kB = 0.0019872041 kcal mol−1 K−1, T = 300 K.
  • Bins: 0.01 nm for residue pairs (density histogram), 0.02 nm for windows and the LIVA fragment (count histogram normalised to probability). Empty bins are left empty (NaN), not interpolated.
  • Reference: every curve is shifted so the populated bin nearest 1.8 nm is zero, and only bins below 1.8 nm are kept. Negative PMF = more probable than at 1.8 nm = attractive well.
  • Full trajectory: the first 5% of frames are dropped as equilibration.
  • Three-residue windows LIV, IVA, VAG, AGX: off-diagonal window pairs pool both orderings (window i on peptide 1 with window j on peptide 2, and j with i), giving 10 unordered pairs.

Halves, mean and uncertainty

  • trim = 5% of all frames; half 1 = frames [trim, mid), half 2 = [mid + trim, end). For the 600,000-frame trajectories this is frames 30,001–300,000 and 330,001–600,000 (1-based) — the same ranges the halved analysis uses — 270,000 frames each.
  • Mean of halves: both half-PMFs are interpolated onto a common grid (from the larger first populated bin to the smaller last bin, capped at 1.8 nm, same bin width) and averaged. Band = |PMF1 − PMF2| / 2.
  • Files: single_residue_pmf_halves_value/ (both halves), single_residue_pmf_mean_value/ (halves + common grid + mean + band), single_residue_pmf_full_value/, three_residue_pmf_halves_value/, fragment_pmf_halves_value/.

Well depths on these pages

Well depth = minimum of the mean-of-halves PMF over r < 1.8 nm (common.well_depth), reported with the distance of the minimum and ± |PMF1−PMF2|/2 at that distance. "Full trajectory" tables use the full-trajectory PMF (no ±). Because every curve is 0 at 1.8 nm, a depth is always relative to that separation; a value near 0 means no well deeper than the reference.

Halved structural analysis (halved/)

  1. Frames 30,001–300,000 (half 1) and 330,001–600,000 (half 2) of com_frames_nowater.dcd.
  2. Filter: LIVA–LIVA distance (:2-5 vs :10-13) < 7 Å → filtered_frames_*_half.nc (not in the snapshot). The number of rows in pep1pep2_angle_*_half.dat is therefore the number of contact frames out of 270,000.
  3. On contact frames: multidihedral phi psi resrange 1-16 (multidihedral_*_half.dat, too large for the snapshot); hbond :2-5,10-13 nointramol → interhbond_*_half.txt (inter-peptide H-bonds among L, I, V, A only; G, X and the caps are not in the mask; Frac = fraction of contact frames); the angle between two vectors → pep1pep2_angle_*_half.dat.
  4. On all frames of each half: end-to-end distance of peptide 1, :2@CA–:7@CA → end_to_end_dist_*_half.dat.
  5. Plots: combined_first_second_half.py (H-bond network and heatmaps, angle and end-to-end histograms).

Because H-bond fractions are per contact frame, a system with fewer contacts can show the same fraction with fewer bonds overall; multiply by the contact fraction for a per-frame comparison (the hbonds_per_all_frames column of figures/halved/halved_summary.csv).

Caveats

  1. Peptide angle vectors. The source cpptraj input defines v1 = :2 → :5 (Leu → Ala of peptide 1) but v2 = :9 → :12 (ACE → Val of peptide 2); the matching vector would be :10 → :13, so this angle is likely off by one residue on peptide 2. The angle histograms and any angle statistic should be read with this in mind until the cpptraj input is fixed and re-run.
  2. livagr folder name. The source folder is livagr/livagr_tripled_time_new_ff/analysis_contined (typo); the snapshot normalises it to data/livagr/ like every other system, and the manifest keeps the real source path.
  3. Halved script label strings. Plot titles and file names in the three LIVAGE folders say LIVAGH_CC / _CN / _NN: a label typo in combined_first_second_half.py. The data are the LIVAGE system. In livagh the script now sets LIVAGH_tripled_time_new_ff_doubled, while the PNGs on disk were written before that edit and are named without _doubled; re-running the script would create differently named files. These pages strip the label to identify the plot type, so either spelling is handled.
  4. Too-large files. Trajectory, pmf_distances.dat and the multidihedral output are not versioned; only their size and time stamp are in the manifest. See Data → files that live only in the source folders.

How to update

cd /hopper/groups/nerenberglab/Project-Peptide_Hydrogel/1-9/60mM_parallel/overall
./update.sh

update.sh re-syncs the snapshot from the source folders (scripts/sync_data.py, read-only on the source), regenerates the figures (scripts/fig_*.py), rebuilds this site (scripts/build_docs.py) and commits a git snapshot with a tag. Only overall/ is ever written. To rebuild just the pages:

cd /hopper/groups/nerenberglab/Project-Peptide_Hydrogel/1-9/60mM_parallel/overall
/hopper/home/jzii2024/miniconda3/envs/pmf/bin/python scripts/build_docs.py

Open docs/index.html in a browser (works straight from the file system).

Browsing history

git -C overall log --oneline --decorate        # list snapshots
git -C overall tag                             # list snapshot tags
git -C overall diff --stat <tagA> <tagB> -- data/   # which results changed
git -C overall show <tag>:data/manifest.json   # manifest of an old snapshot
git -C overall checkout <tag>                  # whole folder (docs too) as it was
git -C overall checkout main                   # back to the latest

The changelog lists every snapshot with the data files that changed per system.

Folder layout of overall/

  • data/<system>/ — snapshot of each analysis folder; data/manifest.json — every source file with status.
  • figures/ — new figures (overview/, cross_system/, halved/, qc/) and their CSV tables; figures/index.json registers them with title and caption.
  • docs/ — this site. docs/systems/previews/ holds downscaled WebP copies of the very large original PNGs.
  • scripts/ — common.py (systems, loaders), style.py (plot look), sync_data.py, figure scripts, build_docs.py.
